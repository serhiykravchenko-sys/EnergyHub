# Telegram Family Assistant 2.4.11

Prepared with EnergyHub 2.4.9. This version replaces false watt-age incidents
with real HA/inverter/Zigbee availability evidence, produces a rolling 24-hour
08:00 technical report, reads Core plus Supervisor warnings/errors, and makes
overload action/attention messages explain the actual trigger, result, device,
and reason. It does not add hardware-control authority.
