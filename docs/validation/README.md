# Validation Records

Use this directory for public-safe supervised test plans and results that span multiple hardware or software components. Hardware-specific validation may remain beside the corresponding document under `hardware/` when that is the clearest source of truth.

Every result should identify the tested version, preconditions, expected outcome, observed outcome, and any remaining limitation.

EnergyHub 1.3.8 repository and monitored deployment evidence is summarized in
the root [README](../../README.md) and [release notes](../../RELEASE_NOTES_1.3.8.md).
Private candidate records and publication tooling are intentionally excluded
from the distribution repository.
