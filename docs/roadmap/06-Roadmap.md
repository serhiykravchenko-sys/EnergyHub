# Roadmap: from reference installation to reusable product

3.x implementation is closed by its owner. Both 3.6.37 apps started. The owner
reports several days of normal observation and accepted public source promotion
on October 28, 2026. This snapshot is not a new tagged GitHub release.

| Direction | Technical work | Household outcome |
| --- | --- | --- |
| Current snapshot | Native plug protection; EH HP1/charging; sensor/BMS evidence; messages and diagnostics | Coordinate a supported home and explain decisions |
| Version 4 architecture review | Configurable device mappings/policies, capability-aware adapters, Core versus Custom delivery, dashboard review | Fewer household-specific code changes and clearer setup |
| AI companion / Mission Control | Installation-aware explanations, authenticated structured intents, text before voice | Ask why something happened and request approved settings/timers |
| Smart EV charging | Compatible charger/vehicle evidence and departure-energy planning | Enough charge for a trip using allowed solar/grid energy |
| Tariff and optional export | Multiple slots/dynamic prices; hardware/contract-specific export | Evaluate import/storage/export without sacrificing reserve |

Safety, ownership, observability, replay tests and privacy-safe diagnostics apply
throughout. Certified life-safety alarms remain independent. No arbitrary
inverter compatibility, universal region support, current AI control or export
capability is claimed by this roadmap. Threat Monitor is separate.
